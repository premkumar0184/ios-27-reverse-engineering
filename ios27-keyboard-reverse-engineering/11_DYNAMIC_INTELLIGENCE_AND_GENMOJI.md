# 11. Apple Intelligence, Writing Tools & Genmoji Architecture

- **Target Build**: iOS 27.2 (Build `24B119`)
- **Hardware Platform**: `iPhone18,3` (SoC: Apple Silicon `t8150` with 16-core Apple Neural Engine)
- **Primary Frameworks**: `TextInputSwift.framework` (VM `0x2b713e000`), `TextInputUI.framework` (VM `0x18fa93000`)
- **Hardware Acceleration**: Apple Neural Engine (`/dev/apple-neural-engine`, direct path client)

## 1. Apple Intelligence Integration Overview

In iOS 27, the keyboard is the primary user-facing touchpoint for on-device Apple Intelligence. Rather than relying solely on static statistical n-gram language models, `TextInputCore` interfaces with `TextInputSwift.framework` to execute transformer-based autoregressive token predictions, semantic proofreading, and generative emoji (Genmoji) vector composition.

## 2. `TextInputSwift.framework` Dissection

- **Location**: Embedded in `dyld_shared_cache_arm64e.69` at VM base address `0x2b713e000` (file offset `0x06d3e000`).
- **Binary Format**: Mach-O 64-bit dylib (ARM64E PAC00).
- **Core Swift Types & Protocols**:
  - `TextInputSwift.SmartReplyGenerator`: Analyzes conversation context from `RTIDocumentState.contextBeforeInput` to generate 3 short contextual response cards.
  - `TextInputSwift.ProofreadingEngine`: Performs non-destructive grammatical and punctuation corrections, annotating corrected spans with `RTITextAnimation` tokens.
  - `TextInputSwift.ContextualPredictionClient`: Manages an asynchronous stream of token probabilities generated by the on-device transformer model.

## 3. Writing Tools & In-Line Predictive Completion

### 3.1 Writing Tools Invocation Protocol
When the user invokes Writing Tools via the `TUIAssistantButtonBarView` icon, the system executes an out-of-process transition:
1. `UIKeyboardImpl` packages the active document selection and preceding text into an encrypted XPC payload.
2. The payload is transferred via `BSServiceConnection` to `/Applications/WritingToolsUIService.app`.
3. `WritingToolsUIService` presents the floating pill UI providing Rewrite, Proofread, and Tone adjustments (Professional, Friendly, Concise).
4. Results are streamed back to `RTIInputSystemClient` as atomic `RTITextOperations` transactions.

### 3.2 In-Line Predictive Completion (Ghost Text)
- The keyboard displays light-gray ghost text extending from the current insertion point.
- **Acceptance Mechanism**: Tapping Space, pressing Tab (on hardware keyboards), or swiping forward on the candidate ribbon commits the suggested token sequence.
- **Rejection Tracking**: If the user continues typing an alternative character, `UIKeyboardImpl` cancels the completion and logs a soft rejection to `inline_completion_rejections` in `rejections.sqlite`.

## 4. Genmoji Vector Rendering Pipeline

Genmoji allows users to generate novel emoji combinations dynamically on-device:

### 4.1 Asset Format: CoreAnimation CAML Archives (`document.caml`)
- Unlike static raster emoji (PNG / ASTC bitmaps in AppleColorEmoji.ttc), Genmoji assets are structured as vector CoreAnimation Model Layer (CAML) XML documents (`document.caml`).
- **Archive Contents**:
  - Root `CALayer` with nested shape layers (`CAShapeLayer`).
  - Cubic Bezier paths (`CGPath`) defining facial contours, expressions, and accessories.
  - Dynamic gradient fills (`CAGradientLayer`) adapting to active system display modes (Standard Dynamic Range vs High Dynamic Range).
  - Adaptive skin tone blending matrices applied at runtime.

### 4.2 Fallback & Interoperability
When Genmoji text is copied or transferred to a client application lacking CAML vector rendering support:
1. **Rich Clients (Messages, Notes)**: Render native vector CAML layers with dynamic lighting and micro-animations.
2. **Standard Text Fields (SMS, Plain Text)**: `CoreEmoji.framework` rasterizes the vector document to a 160x160 PNG image attachment.
3. **External / Non-Apple Fallback**: Converted into an adaptive unicode sequence with a textual fallback description (e.g. `[Emoji: smiling face with cowboy hat and sunglasses]`).

## 5. Clean-Room Android Implementation Strategy

To replicate Apple Intelligence and Genmoji functionality on Android:
1. **Smart Reply**: Integrate Android's `TextClassifier` API (`TextClassifier.suggestConversationActions()`) and Google Play Services on-device Gemini Nano models via AICore.
2. **Writing Tools**: Implement an extensible assistant ribbon using Jetpack Compose that interfaces with on-device LLMs (e.g. Gemma 2B via Mediapipe LLM Inference API).
3. **Genmoji Vector Replacement**: Emulate dynamic emoji composition using SVG / VectorDrawable assets or Google's open-source Emoji Kitchen raster combination lookup tables.
