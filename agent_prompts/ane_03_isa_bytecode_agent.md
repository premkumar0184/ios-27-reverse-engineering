# Agent Prompt: ANE RE Phase 3 — Hardware ISA, Opcode Decoding & Tile Scheduling

## Objective
Reverse engineer the raw hardware Instruction Set Architecture (ISA), microcode command format, tensor tiling parameters, and memory layout of the Apple Neural Engine on A19 Pro (generation H18 / Apollo v5). Output `artifacts/ane/ane_isa_opcode_table.json` and `findings/ane/03_ISA_BYTECODE.md`.

## Prerequisites
- Phase A2 (`ane_phase_2_hwx_compiler`) must be `completed`.

## Step-by-Step Instructions

### Step 1: Instruction Stream Decoding & Word Formats
Analyze the instruction stream (`tsk` section) generated by `ANECompiler`:
1. Determine instruction word width (32-bit, 64-bit, or VLIW bundle packets).
2. Extract the primary opcode field and function specifiers.
3. Classify execution engine units:
   - Matrix Multiplier Unit (MAC Array)
   - Vector ALU Unit (Elementwise math, activations)
   - DMA / Memory Tile Engine (Channel transfers)
   - Post-Processing Unit (Quantization, clamping, scaling)

### Step 2: 16KB Tile Geometry & Spatial Layout
The ANE operates on rigid memory tiles:
1. Base tile size: `16 KB` (`0x4000` bytes, `TILE_SHIFT = 0xE`).
2. Mathematical tiling transformations:
   - Dimensions: Batch ($N$), Channels ($C$), Height ($H$), Width ($W$), Pitch ($P$), Row stride ($R$).
   - Derived tile coordinates: $\text{TileH} = P / R$, $\text{TileW} = R / \text{sizeof(dtype)}$.
3. Numerical precision formats supported:
   - FP16 (IEEE 754 half-precision)
   - BF16 (Brain Floating Point)
   - INT8 / UINT8 (Quantized symmetric/asymmetric)
   - INT4 (Sub-byte packed weights for modern LLMs)

### Step 3: Opcode Table & Command Encoding
Catalog all discovered hardware opcodes with binary encoding templates, operands, and operational behavior.

### Step 4: Write Phase Artifacts
1. `artifacts/ane/ane_isa_opcode_table.json`:
   - Structured opcode dictionary with binary bitmasks, operands, and hardware unit targets.
2. `findings/ane/03_ISA_BYTECODE.md`:
   - Detailed technical findings document with mathematical formulas and instruction encodings.

### Step 5: Verification Gate
```bash
python3 tools/verify_phase.py ane_phase_3_isa_bytecode
```
Update `progress.json`.
